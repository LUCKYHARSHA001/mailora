FUNCTION 1: WHATSAPP MESSAGING & MOBILE OTP VERIFICATION
================================================================================
What it does:
  - Users enter their phone number on the profile page (+91 9391994575).
  - The server generates a secure 6-digit OTP and requests the WhatsApp microservice
    (port 5002) to send: "🔐 Your Mail-or-a verification OTP is: *XXXXXX*".
  - The user enters the OTP to verify their mobile number so they can receive
    upcoming application deadline alerts.

Current Status:
  - Microservice code, routes, and Puppeteer Chrome auto-detection are 100% ready.
  - Sits idle until the microservice is started and paired via QR code.

What Needs to be Done to Make it Work:
  1. Open a new terminal tab.
  2. Start the WhatsApp service:
       cd whatsapp-service
       npm run dev
  3. The terminal will print an ASCII QR code.
  4. On your mobile phone (9391994575), open WhatsApp:
       Settings (or 3 dots) -> Linked Devices -> Link a Device -> Scan the terminal QR code.
  5. The terminal will confirm:
       "[WhatsApp] Session authenticated & saved"
       "[WhatsApp] Client is ready"
       "[Boot] API server running on http://localhost:5002"
  6. Return to your browser (http://localhost:5173/profile), click "Send OTP via WhatsApp".
  7. Check your WhatsApp on your phone, type the 6-digit code into the popup, and verify!
  (Note: You only ever have to scan the QR once; the session is saved permanently in .wwebjs_auth).

FUNCTION 3: CONNECT PERSONAL GMAIL INBOXES (EMAIL INGESTION)
================================================================================
What it does:
  - Allows users to link their Gmail accounts (up to 3) under "Connected Accounts (0/3)".
  - MailOra scans incoming emails for career opportunities (internships, jobs, hackathons,
    interviews) and extracts deadlines.

Current Status:
  - Code, OAuth scopes (gmail.readonly, gmail.modify), and 15-minute polling sync cron
    (services/gmailSync.service.js) are 100% implemented.
  - Needs the Gmail API enabled in Google Cloud Console.

What Needs to be Done to Make it Work:
  1. Open your Google Cloud Console tab (project: AIMENTOR).
  2. In the top search bar, search for "Gmail API".
  3. Click "Gmail API" from the results and click the blue "ENABLE" button.
  4. Return to MailOra Profile (http://localhost:5173/profile).
  5. Under "Connected Accounts", click "G Connect Google Account".
  6. Grant permissions to allow MailOra to read and sync job emails.
  7. The account will appear as "1/3 Active" and begin syncing automatically!
  (Optional for instant push: create a GCP Pub/Sub topic and add GOOGLE_PUBSUB_TOPIC to server/.env).

FUNCTION 4: AI OPPORTUNITY & DEADLINE EXTRACTION (GOOGLE GEMINI)
================================================================================
What it does:
  - When an email arrives, it is published to the Aiven Kafka topic `email-classification`.
  - The classification consumer passes the email snippet to Gemini AI (gemini-2.5-flash).
  - Gemini categorizes the email (interview / job / hackathon / other), identifies the
    pipeline stage, and extracts the deadline date, role, company, and application link.
  - The email is encrypted with AES-256 and saved in MongoDB Atlas.

Current Status:
  - 100% OPERATIONAL & VERIFIED LIVE.
  - Connected to Google Gemini, MongoDB Atlas, and Aiven Kafka.


================================================================================
FUNCTION 5: SCHEDULED WHATSAPP DEADLINE REMINDER ALERTS
================================================================================
What it does:
  - When Gemini discovers an email with an application deadline:
    * Schedules a BullMQ delayed job in Upstash Redis for:
      - 3 days before deadline (if > 3 days away)
      - 1 day before deadline
      - 1 hour before deadline
    * When the delay expires, BullMQ publishes to Kafka `whatsapp-messages`.
    * The server consumes the event and sends a WhatsApp message through the
      WhatsApp microservice directly to the user's phone!

Current Status:
  - Full BullMQ + Redis + Kafka pipeline is tested (170/170 tests passing).
  - Works automatically once Function 1 (WhatsApp phone paired) and Function 3 (Gmail connected) are done!

FUNCTION 6: LIVE IT JOBS SCRAPER & JOBS DASHBOARD (SERPAPI)
================================================================================
What it does:
  - Microservice (port 5001) periodically scrapes Google Jobs via SerpAPI across 7 IT roles:
    (Software Engineer, Frontend Developer, Backend Developer, Full Stack Developer,
     DevOps Engineer, Data Analyst, Cloud Engineer).
  - Displays filtered job listings in the "Job Offers" tab on the frontend.

Current Status:
  - Database connection to MongoDB Atlas verified.
  - Startup database wipe hazard fixed.
  - Needs a SerpAPI API key to fetch live job data.

What Needs to be Done to Make it Work:
  1. Obtain a free SerpAPI key from https://serpapi.com/ (free tier includes 100 searches/mo).
  2. Open serpapiservice/.env and set:
       SERPAPI_KEY=<your-serpapi-key>
  3. Start the SerpAPI service:
       cd serpapiservice
       npm run dev
  4. Trigger initial job fetch:
       node force-refresh.js
     (Or make a POST request to http://localhost:5001/api/jobs/refresh).
  5. Go to http://localhost:5173/jobs (or Job Offers tab) to browse live IT opportunities!
